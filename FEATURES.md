# Current Product Behavior Register

This register describes the browser-local prototype and its optional local AI companion as implemented in this worktree. Source coverage is not proof of executed checks or deployment; current deepening evidence belongs in docs/tasks/deepening-implementation.md. Earlier execution evidence remains in docs/tasks/frontend-only.md.

All application routes use the hash prefix. All personas share one local scenario. Role checks organize the simulation and do not provide security. Original backend behavior remains in Git history.

Stable IDs are retained, including explicit removed entries. The legacy duplicate EMP-10 has been consolidated rather than assigned an ambiguous second identity.

## Current implementation limits

No real login, email, binary upload, production CVs, confidential roles, collaboration across devices, cloud analytics or live experiment measurement. The optional loopback companion uses provider AI for generation only, with a server-only key; it owns no application state, authentication or database. Ordinary flows remain browser-local and work without it. A static URL shares code, not local state; exported JSON contains the entire scenario. Human testing, publishing, CI results and course approval must be verified separately.
